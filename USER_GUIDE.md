# User Guide

## Register

Create a new account using the Register page.

## Login

Log in using your email and password.

## Board

After logging in, the Kanban board is displayed.

Users can:

- Create cards
- Edit cards
- Delete cards
- Drag cards between columns
- Reorder cards

## Worklogs

Open a card to:

- Add hours
- Edit worklogs
- Delete worklogs

## My Hours

Displays:

- Weekly worklogs
- Hours per day
- Weekly total

## Reports

Displays:

- Total hours
- New tasks
- Completed tasks
- Overdue tasks
- Hours by user
- Hours by card

Reports can be exported as CSV.

## Logout

Use the Logout button in the navigation bar.
